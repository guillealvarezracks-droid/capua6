Sobre estos datos (leer antes de usar el panel)

Este panel guarda los datos únicamente en localStorage de este navegador, solo para poder probar la maqueta:

  • No se sincroniza entre dispositivos: lo que ves en este móvil u ordenador no aparece en otro.
  • No es un almacén seguro: no metas aquí datos reales de clientes.
  • No sustituye a la futura base de datos del proyecto: es solo para revisar cómo se comportaría el panel.
  • El botón "Reiniciar datos demo" borra tus cambios de prueba y vuelve a cargar el escenario ficticio de partida.
